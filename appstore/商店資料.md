## 描述（4000）

《一指連鎖》是只能點一次的連鎖益智遊戲。

每一關，你只能選一個機關點下去，之後的一切都交給連鎖反應：炸彈炸開周圍、火箭往前直飛、電球全場一起放電……一波接一波，越後面才被炸到的東西分數越高。

讓所有炸彈都爆炸就過關；剩下的東西越少，星星越多。但每一關只有一個起點能把盤面全部清光——你找得到嗎？

【遊戲特色】
・只點一次：先點一下看打擊範圍，再點一下引爆，接下來只能看著連鎖發生
・唯一解：每一關都只有一個起點能拿三顆星
・假源頭：有些機關看起來像起點，其實要等別人先炸開才會被打到
・100 關：盤面從 5×5 慢慢變大到 8×9，難度一路往上
・每 10 關一種新機關：大炸彈、電球、石塊、鏡子、鑰匙與寶箱、斜射盤、鋼箱、傳送門、定時炸彈、黑洞
・卡關有提示，拿到新的三顆星還會多送提示
・竹林裡的熊貓陪你一起動腦
・木琴配樂和爆炸音效全部即時合成

完全離線就能玩。沒有廣告、沒有內購、不需要帳號，也不蒐集任何資料。

## 審查備註（給 Apple 審查人員）

This is a complete offline puzzle game with 100 handcrafted levels. All game content (code, levels, art, fonts, and procedurally synthesized audio) is bundled in the app; it makes no network requests. No login is required.

How to play: tap one object on the board to preview what it hits, then tap the same object again to detonate it. The chain reaction then plays out automatically. The level is cleared when every bomb has exploded. Level 1 is a guided tutorial. The "提示" (Hint) button shows the solution if needed.
