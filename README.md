# 一指連鎖

只能點一次的連鎖益智遊戲。讓所有炸彈都爆炸才算過關；剩下的東西越少，星星和分數越高。
一共 100 關。前 50 關每 10 關棋盤變大一次（5×5、6×6、6×7、7×8、8×9）；第 51 關起棋盤固定 8×9，改成東西更多、假源頭更多。每 10 關都會多一種新物件。熊貓只出現在場景和吉祥物，棋盤上的元件跟熊貓無關。

## 規則

- 每一關只能引爆一次：點一個機關看它打得到誰，再點同一個引爆。
- **每一關只有一個起點能把全部清光**，其他起點都會留下東西。
- 一顆星：所有炸彈都爆炸。兩顆星：剩下 2 個以內。三顆星：全部清光。
- 分數 = 連鎖得分 × 清掉的比例；全部清光再加 50%。

## 棋盤上的東西

- 炸彈：炸周圍一圈。大炸彈：炸周圍兩圈。
- 火箭：往箭頭方向飛，打中第一個東西。
- 橫向盤：往左、右各打中第一個東西。直向盤：往上、下各打中第一個東西。
- 電球：一顆被打到，全場的電球一起放電，並打到自己上下左右的鄰居。
- 寶石、木箱：自己不會動，要被打到才會消失。石塊：要被打兩次。
- 鏡子（第 31 關起）：火箭和盤的射線打到它會轉 90 度彎，再打中轉彎後的第一個東西。被炸到只會碎掉。
- 鑰匙與寶箱（第 41 關起）：寶箱鎖著時打了沒反應，要先打到鑰匙才打得開，分數是炸彈的 5 倍。
- 斜射盤（第 51 關起）：往四個斜角各打中第一個東西。斜的射線碰到鏡子不會轉彎。
- 鋼箱（第 61 關起）：炸彈、電球、黑洞都弄不壞，只有射線打得壞。
- 傳送門（第 71 關起）：一對門。射線走進一個門，從另一個門出來繼續飛。門打不壞，也不算在要清掉的東西裡。
- 定時炸彈（第 81 關起）：被打到後等 2 波才爆炸，倒數時會擋住射線。它也是炸彈。
- 黑洞（第 91 關起）：把周圍 8 格吞掉，被吞的東西不會發動；被吞掉的炸彈不算爆炸。

每 10 關登場的新物件：第 11 關大炸彈與電球、第 21 關石塊、第 31 關鏡子、第 41 關鑰匙與寶箱、第 51 關斜射盤、第 61 關鋼箱、第 71 關傳送門、第 81 關定時炸彈、第 91 關黑洞。
還沒玩到的新物件，在選關畫面和說明卡裡只看得到影子。

線上直接玩：https://hankhsu1969.github.io/one-tap-chain/

遊戲畫面最下方的「說明」按鈕會列出上面每一種東西的作用、效果和打擊範圍小圖。

## 檔案

- `one-tap-chain.html`：組好的完整遊戲，單一檔案，直接用瀏覽器打開就能玩。
- `index.html`：跟 `one-tap-chain.html` 一模一樣，給 GitHub Pages 當首頁。
- `src/core.js`：遊戲規則（連鎖模擬、星星與計分、讀取關卡），不碰畫面。
- `src/levels.json`：100 關的盤面與唯一解，由 `tools/levelgen.js` 事先算好。
- `src/ui.js`：畫面、操作、特效，以及用 Web Audio 即時合成的配樂與音效。
- `src/page.html`：版面與樣式。
- `tools/levelgen.js`：關卡設計工具。大量產生盤面，只留下「唯一解」的，再加上看起來像起點、其實不是的「假源頭」來提高難度。
- `art4/`：H 站（Higgsfield GPT Image 2）產的圖：棋盤元件（5×4 格的圖集）、熊貓角色、背景、標題頁封面（直式 `cover_p.webp`、橫式 `cover_w.webp`）。`assets.json` 是內嵌用的版本。
- `cover/`：H 站產的宣傳封面，桌機橫式 1920×1080、手機直式 1080×1920。桌機版也是分享網址時的預覽圖。兩張縮小後都放進遊戲標題頁：直式螢幕用手機版，橫向螢幕用桌機版並鋪滿整個視窗。
- `build.js`：把上面幾個檔案組成 `one-tap-chain.html` 和 `index.html`。
- `test/`：規則與 100 關檢查、自動試玩、音量量測。

## 重新組合

```
node build.js
```

## 重新設計關卡

```
node tools/levelgen.js 300 51     # 只重做第 51 關以後（前面的關卡不動，玩家的星星才不會白拿）。數字越大挑得越仔細
node tools/levelgen.js 300 61 70  # 只重做第 61–70 關
node build.js
```

注意：目前的第 1–50 關是用比較早版本的工具做的，現在的工具重做會得到不一樣的盤面，玩家已經拿到的星星就對不上了，所以不要從第 1 關整個重做。

## 檢查

```
node test/sim3.js                 # 檢查 100 關：清得光、至少 2 顆炸彈、只有一個起點能三星、新物件數量正確
node test/play3.js <截圖資料夾>    # 自動試玩（需要 Playwright）
node test/audio.js                # 量測配樂與音效音量（需要 Playwright）
```
