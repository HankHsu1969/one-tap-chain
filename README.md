# 一指連鎖

只能點一次的連鎖益智遊戲。讓所有炸彈都爆炸才算過關；剩下的東西越少，星星和分數越高。
一共 50 關，每 10 關棋盤變大一次（5×5、6×6、6×7、7×8、8×9）。熊貓只出現在場景和吉祥物，棋盤上的元件跟熊貓無關。

## 規則

- 每一關只能引爆一次：點一個機關看它打得到誰，再點同一個引爆。
- **每一關只有一個起點能把全部清光**，其他起點都會留下東西。
- 一顆星：所有炸彈都爆炸。兩顆星：剩下 2 個以內。三顆星：全部清光。
- 分數 = 連鎖得分 × 清掉的比例；全部清光再加 50%。

## 棋盤上的東西

- 炸彈：炸周圍一圈。大炸彈：炸周圍兩圈。
- 火箭：往箭頭方向飛，打中第一個東西。
- 橫向盤：往左、右各打中第一個東西。直向盤：往上、下各打中第一個東西。
- 電球：一顆被打到，全場的電球一起放電，並打到自己上下左右的鄰居。
- 寶石、木箱：自己不會動，要被打到才會消失。石塊：要被打兩次。

遊戲畫面最下方的「說明」按鈕會列出上面每一種東西的作用、效果和打擊範圍小圖。

## 檔案

- `one-tap-chain.html`：組好的完整遊戲，單一檔案，直接用瀏覽器打開就能玩。
- `src/core.js`：遊戲規則（連鎖模擬、星星與計分、讀取關卡），不碰畫面。
- `src/levels.json`：50 關的盤面與唯一解，由 `tools/levelgen.js` 事先算好。
- `src/ui.js`：畫面、操作、特效，以及用 Web Audio 即時合成的配樂與音效。
- `src/page.html`：版面與樣式。
- `tools/levelgen.js`：關卡設計工具。大量產生盤面，只留下「唯一解」的，再加上看起來像起點、其實不是的「假源頭」來提高難度。
- `art4/`：H 站（Higgsfield GPT Image 2）產的圖：棋盤元件、熊貓角色、背景、主視覺。`assets.json` 是內嵌用的版本。
- `build.js`：把上面幾個檔案組成 `one-tap-chain.html`。
- `test/`：規則與 50 關檢查、自動試玩、音量量測。

## 重新組合

```
node build.js
```

## 重新設計關卡

```
node tools/levelgen.js 300        # 數字越大挑得越仔細，300 大約 45 秒
node build.js
```

## 檢查

```
node test/sim3.js                 # 檢查 50 關：清得光、至少 2 顆炸彈、只有一個起點能三星
node test/play3.js <截圖資料夾>    # 自動試玩（需要 Playwright）
node test/audio.js                # 量測配樂與音效音量（需要 Playwright）
```
